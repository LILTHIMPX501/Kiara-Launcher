# Vérifications avant publication

- [ ] Copie de sauvegarde du projet et de la clé de signature hors dépôt
- [ ] Vérifier `git status` et `git ls-files` pour exclure clés, mots de passe, sauvegardes et `local.properties`
- [ ] Vérifier les ressources, bibliothèques et leurs licences
- [ ] Ajouter la licence choisie avec l'année et le titulaire appropriés
- [ ] Remplacer l'identifiant `com.example.myapplication` si souhaité **avant** une nouvelle diffusion (attention : changer l'identifiant crée une autre application)
- [ ] Vérifier les numéros de version et les éventuels conflits de signature
- [ ] Compiler le projet cloné dans un dossier vierge
- [ ] Tester le nouvel APK Release et son import/export
- [ ] Préparer une capture d'écran sans données personnelles
- [ ] Créer un dépôt GitHub public seulement après revue des fichiers
- [ ] Joindre l'APK Release signé à une GitHub Release, jamais le `.jks`
